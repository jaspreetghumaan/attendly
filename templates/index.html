How SmartAttend Works

Taking attendance with SmartAttend follows three simple steps.

  1. 1

    Teacher Generates a QR Code

    The teacher selects a class or subject and creates an attendance session.

  2. 2

    Student Scans the Code

    The student scans the session's QR code using a compatible device.

  3. 3

    Attendance Is Recorded

    The system validates the request and records attendance.
